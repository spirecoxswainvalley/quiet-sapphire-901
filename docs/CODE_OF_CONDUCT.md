# Code of Conduct

## Our pledge

We want a friendly, welcoming space for everyone, regardless of experience level.

## Expected behaviour

- Be respectful and constructive.
- Assume good intentions.
- Accept feedback gracefully.

## Unacceptable behaviour

- Harassment or personal attacks.
- Sharing private information without consent.

## Enforcement

Report issues to the maintainers. Reports are reviewed promptly and fairly.
